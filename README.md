Weather Classification AI Project
📌 Project Description

This project uses Machine Learning algorithms to classify weather conditions based on environmental features such as temperature, humidity, and wind speed.

The system predicts different weather types automatically using trained classification models.

🌦️ Weather Classes
Sunny ☀️
Rainy 🌧️
Cloudy ☁️
🤖 Machine Learning Models Used
K-Nearest Neighbors
Random Forest Classifier

The project compares multiple models to determine the best performing algorithm.

📊 Dataset Information

The dataset contains weather-related information including:

Temperature (C)
Humidity
Wind Speed (km/h)
Weather Summary
