# 🌤️ Weather Classification AI Project

## 📌 Project Description
This project uses Machine Learning algorithms to classify weather conditions based on environmental features such as temperature, humidity, and wind speed.

The system predicts weather conditions automatically using trained classification models.

---

## 🌦️ Weather Classes
- Sunny ☀️
- Rainy 🌧️
- Cloudy ☁️

---

## 🤖 Machine Learning Models Used
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Random Forest Classifier

The project compares multiple models to determine the best performing algorithm.

---

## 📊 Dataset Information

The dataset contains weather-related information including:

- Temperature (C)
- Humidity
- Wind Speed (km/h)
- Weather Summary

---

## 📁 Dataset Source
[Weather Dataset CSV](https://raw.githubusercontent.com/245094-png/weather-ml-project/main/weatherHistory.csv)

---

## 📈 Model Accuracy

| Model | Accuracy |
|---|---|
| KNN | ~40% |
| Decision Tree | ~60% |
| Random Forest | ~65% – 80% |

---

## ⭐ Best Model
Random Forest achieved better performance and higher prediction accuracy.
